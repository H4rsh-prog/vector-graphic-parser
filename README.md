# Vector Graphic Parser

This project is a Spring Boot application for parsing and working with vector graphic content.

## Requirements

- Java 17+
- Maven wrapper or Maven 3.9+

## Run locally

```bash
./mvnw spring-boot:run
```

## Test

```bash
./mvnw test
```

## Build

```bash
./mvnw package
```
